Frame Validator


Type a UDS request yourself. The app compares it with the diagnostic definitions from the MDD and explains what is valid, missing, or incorrect.




Shared MDDNo MDD loaded






Enter hexadecimal bytes. Spaces are optional.






















Response Decoder


Paste an ECU response. The app identifies positive or negative responses, the related UDS service, NRC meaning, and response fields available in the MDD.




Shared MDDNo MDD loaded






The first byte is interpreted as the positive response SID, or 0x7F for a negative response.





















DTC Decoder


Decode UDS ReadDTCInformation (0x19 / positive response 0x59), resolve DTC names and descriptions from the MDD, decode the DTC status byte, and inspect snapshot or extended-data records.




Shared MDDNo MDD loaded






Enter the ECU response beginning with 0x59. For snapshot responses (sub-function 0x04), the decoder shows the DTC, status, record number and raw snapshot payload. Snapshot physical values are decoded only when their structure can be determined from the diagnostic description.


























Diagnostic Sequencer


Create several diagnostic sequences, configure each frame, and export them for later vehicle integration.





Sequence storage
Sequences are saved automatically and restored when the application starts. The Builder and Sequencer write through a UDS writer trait. The default implementation writes raw .bin files; another implementation can later write to sockets or another transport.
